The problem

The problem

People frequently mistake a list page for a user profile. This creates confusion and interrupts the experience.

The goal

Redesign the list page so it clearly stands apart from a profile page.

UI/UX audit

UI/UX audit · Current state

Where the list loses focus

How to explore: click a pink marker to inspect the related finding.

  1. Portrait, handle, location, counts, rating, and actions appear before the first place. This creates a high information load before browsing begins.

  2. The large image acts as decoration while the user’s main task is to understand the list and explore its places.

  3. Places, Map, and Comments sit inside a rounded panel with low contrast, so the page’s main modes do not read as clear navigation.

  4. Quick categories are useful. Lower-frequency filters can sit behind one clear Filter control, keeping the first view focused.

  5. A single two-column grid makes every place equal. Category swimlanes could give people clearer ways to start exploring.

Desk review based on supplied screens. Behaviour and user comprehension will be validated in testing.

Section 05

Final thoughts

Make the collection page the public destination for places and creator context.

01

Lead with the collection. Keep the creator’s identity, Follow, Message, and relevant details on the same page.

02

Keep the owner’s profile for editing their details. Avoid repeating the same public information across two pages.

03

Run an A/B test against the current page before deciding whether this approach improves following and place discovery.
